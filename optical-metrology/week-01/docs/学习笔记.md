## 本周问题

一个理想点为什么会在探测器上变成斑？“像差”和“像面没有对准焦点”分别描述什么？观测到的位置、形状或清晰度变化，又可能由探测器和算法中的哪些因素造成？

## 成像链路

目标或标记 → 照明与目标相互作用 → 成像 / 收光光路 → 探测器 → 估计算法。

- 波前像差属于光路模型。
- 像元积分、采样、噪声和饱和属于探测模型。
- ROI、阈值、背景扣除与拟合属于算法模型。
- 改变一层时先固定其他层，之后再研究它们的耦合。

## 近轴薄透镜

在常用实物距、实像距均取正的薄透镜约定下：

$$\frac{1}{f}=\frac{1}{u}+\frac{1}{v}, \qquad m=\frac{y'}{y}=-\frac{v}{u}.$$

当 `f = 50 mm`、`u = 150 mm` 时，`v = 75 mm`，`m = −0.5`。像距、物距和焦距使用相同长度单位。符号应与光线方向和坐标定义一起说明。

取光线向量 `r = [y, θ]ᵀ`：

$$T(d)=\begin{bmatrix}1&d\\0&1\end{bmatrix},\qquad L(f)=\begin{bmatrix}1&0\\-1/f&1\end{bmatrix}.$$

$$M=T(v)L(f)T(u)=\begin{bmatrix}A&B\\C&D\end{bmatrix},\qquad B=0$$

是物面与像面满足一阶成像条件的判据。这个模型能检查共轭位置、近轴光线高度和横向放大率；它不含高阶像差项，不能预测彗差等波前误差。

## 单缝衍射

理想均匀照明单缝的 Fraunhofer 强度：

$$\frac{I}{I_0}=\left(\frac{\sin\beta}{\beta}\right)^2,\qquad \beta=\frac{\pi a\sin\theta}{\lambda}.$$

第一暗纹满足 `a sin θ = λ`。屏幕距离 `L` 时，精确几何位置为 `x₁ = L tan(arcsin(λ/a))`；小角度近似为 `x₁ ≈ λL/a`。

默认值 `λ = 550 nm`、`a = 50 μm`、`L = 1.2 m`，小角度结果为 `13.200 mm`，精确屏幕几何结果约为 `13.201 mm`。曲线使用精确的 `θ = atan(x/L)`，不是把近轴近似说成精确公式。

## 孔径与离焦

理想圆孔在焦面上的 Airy 首暗环半径：

$$r_{Airy}\approx1.22\frac{\lambda f}{D}.$$

在 `λ = 550 nm`、`f = 50 mm`、`D = 10 mm` 时，`r_Airy = 3.355 μm`。平行入射的近轴光锥，若传感器沿轴向偏离焦面 `Δz`，几何弥散圈直径近似为：

$$d_{defocus}\approx D\frac{|\Delta z|}{f}.$$

例如 `Δz = 1.2 mm` 时，几何直径约 `240 μm`。Airy 首暗环和几何离焦圈是两个分别计算的量，不是合成后的 PSF。

## 术语边界

- **孔径**描述光束口径；**视场**描述离轴物点范围。
- **离焦**描述像面相对焦面的位置关系；它既可在几何光线图里表现为弥散圈，也可在波动模型里写为瞳面相位项。离焦也常作为低阶波前像差项，因此两种说法相关，不能理解成完全互斥。
- **像差**描述成像相对理想参考的偏离，不包括像元噪声、欠采样或 ROI 截断等所有误差。
- “图像呈彗差样拖尾”是现象描述；“拟合支持彗差项”是模型判断；“某元件偏心”是机械根因假设，需要额外证据。

目标上下移动时图像中心也移动，应先考虑远心性、主光线角度或光轴倾斜等几何关系，并设计对照；不能只凭位置变化就判定彗差。
