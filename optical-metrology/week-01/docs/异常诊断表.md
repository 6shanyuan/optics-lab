# 第 1 周异常诊断表

| 观察到的现象 | 候选原因 | 优先追加的对照 | 判断边界 |
| --- | --- | --- | --- |
| 整体模糊 | 离焦、球差、欠采样 | 已知离焦序列；比较光学高分辨图与像元采样图 | 单张图不能区分光学模糊与欠采样。 |
| 方向性模糊 | 像散、照明偏心、运动或读出效应 | 比较焦前 / 焦后；旋转目标方向或改变照明对称性 | 椭圆点像只是观测描述，不足以单独确定像散。 |
| 拖尾并伴随位置偏移 | 彗差、瞳面遮挡、目标不对称、ROI 截断 | 分别改变瞳面相位和振幅；扩大 ROI；反转目标方向 | 质心会受目标形状和裁剪影响。 |
| 位置随焦点变化 | 非对称成像、标记响应、放大率或光轴耦合 | 使用对称目标；更换算法；联合检查图像中心和放大率 | 不能只凭焦点相关位移认定机械根因。 |
| 中心清晰、边缘变差 | 场曲、像面倾斜、视场相关像散或渐晕 | 多视场测最佳焦面并比较局部点像 | 中心视场不能代表整个视场。 |

## 使用顺序

1. 区分亮度 / 信噪比变化，还是形状、位置、焦点或估计值变化。
2. 看原始数据是否变化，还是只有处理结果变化。
3. 记录变化与焦点、视场、波长、目标方向及算法参数的关系。
4. 写出候选原因各自的预测，再选一个能拉开预测差异的对照。
5. 结论可以停在“现象层”或“光学模型层”；没有独立证据时不跳到部件维修结论。

## 原课堂的五种对照实验

| 对照实验 | 主要观察 | 区分方向 |
| --- | --- | --- |
| 扫描焦点 Z | 清晰度是否先改善后恶化，各视场最佳焦面是否相同 | 离焦与其他机制 |
| 改变视场 | 边缘是否增强、形状是否变化 | 场依赖与整体问题 |
| 改变曝光时间 | 拖尾是否随曝光时间改变 | 运动模糊与静态光学效应 |
| 改变照明强度 | 对比度、噪声、饱和是否变化 | 信噪比和探测问题 |
| 重复拍摄 | 异常是否稳定重现 | 随机变化与系统性误差 |

## 课堂案例

中心清晰、左右边缘模糊；移动探测器后边缘改善、中心变差。优先验证“不同视场最佳焦面不一致”，再通过二维视场的最佳焦面分布、局部点像形状与方向区分场曲、像面倾斜等机制。

## 三层证据

观测事实：右侧点像非对称拖尾。模型解释：波前拟合提示彗差项可能较大。物理根因：某元件偏心或倾斜可能导致该像差。三者不能互相替代；拟合系数不足以直接决定维修部件。
