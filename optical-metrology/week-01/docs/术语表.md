# 第 1 周术语表

| English | 中文 | 说明 |
| --- | --- | --- |
| Object plane | 物面 | 放置物体或标记的平面；成像时与像面互为共轭。 |
| Image plane | 像面 | 光学系统把物点映射到像点所在的平面。 |
| Optical axis | 光轴 | 近轴模型中的参考中心线。 |
| Aperture stop | 光阑 / 孔径光阑 | 限制通过系统的有效光束口径。 |
| Aperture angle | 孔径角 | 由物点看见的光锥半角，描述光束张角。 |
| Field angle | 视场角 | 离轴物点相对光轴的角位置。 |
| Paraxial optics | 近轴光学 | 假设光线靠近光轴且角度较小的一阶模型。 |
| Focal length | 焦距 `f` | 薄透镜使近轴平行光会聚到焦点的距离。 |
| Magnification | 横向放大率 `m` | 像高与物高之比；常用约定下实像 `m = −v/u`。 |
| Aberration | 像差 | 波前或成像相对选定理想参考模型的偏离。 |
| Defocus | 离焦 | 像面偏离选定焦面；不是所有模糊现象的同义词。 |
| Diffraction | 衍射 | 有限孔径导致波场扩展，理想点像也有有限尺寸。 |
| Optical path difference (OPD) | 光程差 | 实际波前与参考波前之间的差 `W`，单位是长度。 |
| Point spread function (PSF) | 点扩散函数 | 系统对理想点目标的强度响应。 |
| Telecentricity | 远心性 | 物方或像方主光线近似平行于光轴的布局特性。 |

> 说明：本项目不使用未说明约定的 Zernike 一维编号；后续涉及波前基函数时会显式列出公式和归一化。

## 逐字稿补充术语

| English | 中文 | 定义 |
| --- | --- | --- |
| Entrance pupil | 入瞳 | 孔径光阑经前方光学系统形成的像。 |
| Exit pupil | 出瞳 | 孔径光阑经后方光学系统形成的像。 |
| Field stop | 视场光阑 | 主要限制能观察到的物体范围。 |
| Diffraction grating | 光栅 | 周期结构产生离散衍射级次；产生衍射的孔径不一定是光栅。 |
| Numerical aperture | 数值孔径 | NA=n sinα；须说明物方或像方及介质。 |
| Pupil function | 瞳函数 | P=Aexp(iφ)，A 为振幅透过率，φ 为相位。 |
| Coherent superposition | 相干叠加 | 先叠加带相位的电场，再求时间平均强度。 |
