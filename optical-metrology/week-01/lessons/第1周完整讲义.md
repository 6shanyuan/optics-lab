# 第 1 周完整讲义：传感成像光路与像差概念

> 本讲义按 12 周学习计划整理第 1 周，围绕“一个理想点为什么会在探测器上变成斑；观察到异常后，怎样提出候选原因并设计区分条件”。交互网站、光路图、Notebook、题库和诊断表是本讲义的配套材料。

## 本周目标与交付

学习结束后，应能：

1. 按顺序说清目标、照明、成像/收光光路、探测器和估计算法各自会改变什么。
2. 区分光阑口径与视场范围，使用薄透镜公式计算像距和横向放大率。
3. 解释有限孔径为何使理想点产生衍射斑，并计算单缝首暗纹的教学示例。
4. 说明传感器像面偏焦与高阶像差的不同观测表现，同时知道“离焦”本身也可作为波前低阶像差项。
5. 用一阶 ABCD 矩阵核对共轭成像，指出它不能预测彗差等高阶像差。
6. 对模糊、方向性模糊、拖尾、焦点相关位移、边缘变差等现象，至少保留两个候选并提出能区分它们的检查。

建议本周投入 12 小时：概念阅读 4 小时、手算与推导 2 小时、软件仿真 4 小时、解释和复盘 2 小时。交付物为成像链路图、近轴计算 Notebook、中英术语表、五类异常诊断表和一页复盘。

## 1. 先界定“光学测量”中的三层问题

同一个传感信号可能经过多个环节。讨论异常前，先判断它属于哪一层：

| 层次 | 可能改变的量 | 本周例子 |
| --- | --- | --- |
| 传感器前端光学系统 | 波前、点扩散函数、图像几何映射 | 离焦、球差、彗差、像散、场曲 |
| 光电探测器 | 像元积分、采样、噪声、饱和 | 欠采样让边缘锯齿；读出噪声增加散布 |
| 估计算法 | ROI、背景、阈值、拟合和最终位置 | 裁剪拖尾会拉动质心；模型失配会偏移拟合结果 |

本计划中“传感器相关光路像差”指目标到传感器之间光学系统的偏差，不把噪声或算法误差称作像差。另一个相关问题是“用传感器测量被测投影物镜的像差”：被测物镜和测量传感器是两个不同角色，必须把自有测量光路的误差与被测系统误差分开。

通用测量链路为：

**目标或标记 → 照明与目标相互作用 → 成像/收光光路 → 探测器 → 估计算法**

新增的候选原因应落到链路中的某一层，并提出相应对照。例如，扩大 ROI 是检查算法裁剪的对照；改变离焦位置是检查焦点依赖的对照；提高采样或对照连续模型是检查探测器采样的对照。

## 2. 近轴成像：先把理想几何关系算对

### 薄透镜和符号约定

本周的薄透镜示例采用实物、实像的正距离写法：物距 u、像距 v、焦距 f 都用同一长度单位，并取正值。薄透镜成像关系为：

**1/f = 1/u + 1/v**

因此 **v = fu/(u − f)**。实像的横向放大率为：

**m = y′/y = −v/u**

负号表示实像相对物体倒置。若讨论虚物、虚像或其他符号体系，必须先声明约定；不能把不同约定的正负号混用。

例：焦距 f = 50 mm，实物距 u = 150 mm。

- 1/v = 1/50 − 1/150 = 1/75 mm⁻¹，因此 v = 75 mm。
- m = −75/150 = −0.5。
- 物高 4 mm 时，像高为 −2 mm：图像高度缩小一半并倒置。

### ABCD 矩阵的意义

在近轴条件下，用光线状态向量 [y, θ] 表示光线高度 y 与小角度 θ。传播距离 d 和理想薄透镜焦距 f 的矩阵分别是：

**T(d) = [[1, d], [0, 1]]**  
**L(f) = [[1, 0], [−1/f, 1]]**

物面到像面的矩阵是 **M = T(v) L(f) T(u) = [[A, B], [C, D]]**。输出高度满足 **y′ = A y + B θ**。当 **B = 0**，像高与同一物点发出的近轴光线初始斜率无关，一阶成像条件成立。

将三个矩阵相乘，**B = u + v − uv/f**。代入薄透镜关系后 B = 0。上述示例得到 A = −0.5、B = 0、C = −0.02 mm⁻¹、D = −2。A 对应横向放大率；B 的单位为长度，C 的单位为倒长度。

ABCD 矩阵是一阶近轴模型。它适合核对焦点、共轭、放大率和光线高度；即使追迹更多条光线，也不会自动出现球差、彗差等高阶效应。高阶像差需要相应的波前、真实光线或更完整的成像模型。

## 3. 光阑与视场不是一回事

- **光阑 / 孔径光阑**限制光束横向范围，主要改变通光量、光束张角、衍射尺度和离焦几何弥散圈。
- **视场**描述目标点相对光轴的离轴位置或角度范围，主要用于讨论视场内不同位置的成像差异。
- **孔径角**描述一个物点看到的光锥半角；**视场角**描述物点离轴的程度。

把光阑收小会截去光束边缘，但不等于把物点移到视场边缘。理想薄透镜练习会把视场像差等因素省略，因此只说明一阶几何关系。

## 4. 理想点为何会变成有限光斑

理想几何光学把点成像到点；真实光路有有限孔径。有限孔径限制波场，使能量扩散为点扩散函数（PSF）。因此，即便系统没有像差，理想点也会形成有限大小的衍射图样。光学斑不等于缺陷，图像中记录到的斑还会叠加探测与算法影响。

### 单缝 Fraunhofer 衍射演示

均匀照明、单色、理想单缝处在远场 Fraunhofer 条件时：

**I/I₀ = (sin β / β)²，β = πa sinθ / λ**

第一级暗纹满足 **a sinθ₁ = λ**。在距离为 L 的平面上，若屏幕横坐标是 x，则 **θ = atan(x/L)**，从而可用精确几何计算：

**x₁ = L tan(asin(λ/a))**

若 λ/a 很小，使用小角度近似 **x₁ ≈ λL/a**。

例：λ = 550 nm、缝宽 a = 50 μm、屏距 L = 1.2 m。

- 小角度估算：x₁ ≈ 13.200 mm。
- 精确屏幕几何：x₁ ≈ 13.201 mm。
- 缝宽减半，首暗纹位置约扩大一倍；波长或屏距增加，图样也变宽。

曲线是解析理想模型，不模拟近场传播、透镜像差、部分相干、非均匀照明或像元积分。网站里的曲线属于单缝远场模型，不能拿来当圆孔 PSF。

### 圆孔 Airy 斑与离焦圈分开读

焦面上理想圆孔第一暗环半径的近轴近似是：

**r_Airy ≈ 1.22 λ f / D**

λ = 550 nm、f = 50 mm、孔径直径 D = 10 mm 时，r_Airy ≈ 3.355 μm。

像面相对几何焦面偏移 Δz 时，理想会聚光锥在新像面形成的近轴几何弥散圈直径近似为：

**d_defocus ≈ D |Δz| / f**

如果 Δz = 1.2 mm，则 d_defocus ≈ 240 μm。孔径越大、离焦量越大，几何圈越大；焦距越长，几何圈越小。

这里的 Airy 半径和几何离焦圈是两个单独的估算。它们不是经波动传播得到的合成离焦 PSF。精确离焦点像还要考虑瞳函数、相位、像差、波长、相干性和探测采样。

## 5. 像面偏焦与像差：联系和区别

本周用“像面相对设计像面的位置偏移”描述对焦误差，用“波前或成像相对选定理想参考的偏离”描述残余像差。它们都可能使点像变差，而且具体光学表达中，离焦也常作为低阶波前像差项（defocus）表示。因此这是便于排查的分层方式，不是说离焦在物理上完全不属于像差。

初识的像差包括：

| 名称 | 常见直觉描述 | 本周可做的观察 |
| --- | --- | --- |
| 离焦 | 像面不在选定焦面；点像扩展 | 前后移动像面，看斑尺度与清晰度如何变化 |
| 球差 | 不同孔径高度的光线不在同一轴上焦点 | 改变孔径时，最佳焦面和斑形可能一起变化 |
| 彗差 | 离轴点像出现不对称、带尾特征 | 观察点像不对称，但同时排除目标不对称与 ROI 裁切 |
| 像散 | 两个正交截面具有不同焦点位置 | 比较不同焦面和 x/y 截面 |
| 场曲 | 最佳焦面随视场位置变化 | 在多个视场测最佳焦面 |
| 畸变 | 像点坐标映射随视场偏离理想关系 | 比较视场位置映射，而非只看一个点像 |
| 色差 | 成像随波长改变 | 多波长对照，并固定其他条件 |

“图像像彗差”是观测描述；“拟合更支持某个彗差波前项”是模型估计；“某片镜头偏心”是机械根因假设。三者证据门槛不同。单张拖尾图像不足以直接判定镜片损坏。

## 6. 测量传感器与被测投影物镜

标记成像传感器的示意链路：照明、标记、成像或收光光路、光阑、探测器、位置估计算法。它说明信号形成的功能环节，不代表某一具体设备处方。

光刻机投影像差测量的概念图中，被测投影光学系统把测试目标转化为可观测信号，测量传感器记录信号并估计参数。传感器自己的成像误差、响应偏差和算法误差都可能污染反演。因此“测得像差”需要明确测量模型、仪器自身误差和可识别性；不能将传感器图像中的每个形状直接等同于投影物镜缺陷。

不同传感器可以采用成像、干涉、衍射或其他结构。本周图示仅是教学上的功能关系，不声称具体机台内部结构。

## 8. 五类异常的首轮判断

本周交付的完整表格在 [五类异常诊断表](../docs/异常诊断表.md)。首轮判断原则是列出至少两个候选，选择使候选给出不同预测的对照：

1. **整体模糊**：像面偏焦、球差、采样不足；扫离焦并比较高分辨光学图与像元采样图。
2. **方向性模糊**：像散、照明偏心、运动或读出方向效应；比较焦前焦后图并旋转目标或改变照明。
3. **拖尾和位置偏移**：彗差、遮挡、目标不对称、ROI 截断；扩大 ROI、反转目标或分别改变波前与瞳振幅。
4. **位置随焦点变化**：非对称成像、标记响应、放大率或光轴耦合；使用对称目标并更换定位算法做对照。
5. **中心清晰、边缘变差**：场曲、像面倾斜、视场相关像散或渐晕；测多个视场的最佳焦面和局部点像。

记录需区分观测、估计和根因。证据不足时保留不确定性。

## 9. 练习与答案解析

### 题 1：孔径与视场各描述什么？

**答案：**孔径描述光束通过系统的口径；视场描述目标点离轴的位置范围。收小光阑不等于把目标移到视场边缘。

### 题 2：f = 50 mm、u = 150 mm，求 v 和 m。

**答案：**1/v = 1/50 − 1/150 = 1/75，所以 v = 75 mm；m = −v/u = −0.5。负号表示实像倒置。

### 题 3：无像差的有限孔径系统为什么仍会把理想点成像为斑？

**答案：**有限孔径限制波场，产生衍射 PSF。斑的存在本身不证明像差。

### 题 4：λ = 550 nm、a = 50 μm、L = 1.2 m，求单缝首暗纹位置。

**答案：**小角度估算为 λL/a = 13.200 mm；x = L tan(asin(λ/a)) 得约 13.201 mm。两者接近是因为 λ/a = 0.011 很小。

### 题 5：ABCD 矩阵的 B = 0 表示什么？它能预测彗差吗？

**答案：**在这里表示像高不依赖该物点发出近轴光线的初始角度，满足一阶共轭成像。ABCD 近轴矩阵是线性一阶模型，不能预测彗差。

### 题 6：看到椭圆或拖尾点像，可以立即判定像散或彗差吗？

**答案：**不可以。目标本身、照明偏心、瞳面遮挡、欠采样、ROI 截断等都可能产生相似外观。需比较焦前焦后、改变目标方向或扩大 ROI 等对照。

### 题 7：像元噪声是像差吗？

**答案：**不是。噪声属于探测器层面的随机变化；它可以让测得的点像不稳定，但不等于波前误差。

### 题 8：当目标上下移动时图像中心也移动，先检查什么？

**答案：**先检查远心性、主光线角度、光轴倾斜、放大率或系统几何耦合；再用焦点序列和点像形状补充证据。仅凭位置变化不能认定彗差。

## 12. 复盘

本周最重要的判断是：先说明观测来自测量链路中的哪一层，再说明模型能支持哪种结论。理想有限孔径会产生衍射斑；离焦、像差、探测器采样和算法也会改变记录结果，但对应的物理层和区分实验不同。

回顾反思题：目标上下移动时图像中心也移动，下一项最有价值的对照是什么？写下一个几何候选、一个像差候选，并指出哪个观测能区分它们。
