# 光学测量学习

本主题按周归档光学成像、测量和问题定位学习材料。每周目录应同时保存课程正文、公式条件、图示或交互、练习解析、复盘记录和可运行计算文件，避免只留下一个演示页面。

## 学习范围与进度

- 总路线：12 周、每周 12 小时必做，最多 3 小时扩展；目标是从传感器相关成像光路建立问题定位思路。
- 当前已归档：第 1 周“传感成像光路与像差概念”。

## 归档约定

每周新增独立的 week-NN 文件夹。周目录按需要包含 lessons/、docs/、notebooks/、public/ 和交互网站源码。新增内容应注明学习状态、公式和单位、模型假设、例题答案及来源；教学示意、理想解析模型与真实设备数据需明确区分。
